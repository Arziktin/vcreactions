# VCReactions

Мод для Minecraft Fabric, который озвучивает события через Simple Voice Chat.

## Возможности

- **Реакция на удар** — звук при получении урона
- **Реакция на комбо** — звук при серии ударов (по умолчанию 3 удара за 2.5 секунды)
- **Реакция на падение** — звук при приземлении после падения больше 3 блоков
- **Реакция на окружение** — звук при уроне от огня, лавы, утопления или замерзания
- **Реакция на смерть** — звук при смерти

Звуки подмешиваются в исходящий поток микрофона, поэтому игроки рядом слышат их позиционно.

## Требования

- Minecraft 1.26.2
- Fabric Loader 0.19.3+
- Fabric API 0.152.1+
- Simple Voice Chat 2.6.22+
- Mod Menu 20.0.1+ (опционально, для доступа к настройкам)

## Управление

- **Клавиша K** — открыть меню настроек
- Через **Mod Menu** — также доступно меню настроек

## Настройки

- Включение/выключение каждой реакции отдельно
- Общий выключатель всех реакций
- Ползунок громкости (0-100%)
- Кнопки теста для каждого звука

Настройки сохраняются в `config/vcreactions.json`

## Пользовательские звуки

Вы можете заменить синтезированные звуки своими WAV-файлами:

1. Создайте папку `config/vcreactions/`
2. Поместите туда WAV-файлы с именами:
   - `hit.wav` — звук удара
   - `combo.wav` — звук комбо
   - `fall.wav` — звук падения
   - `environment.wav` — звук урона от окружения
   - `death.wav` — звук смерти

**Требования к файлам:** 48 кГц, 16 бит, моно

## Сборка через GitHub Actions

Поскольку у вас нет Java 25 и интернета для скачивания Minecraft локально:

1. Создайте репозиторий на GitHub
2. Загрузите все файлы проекта
3. Откройте **Actions** в репозитории
4. Запустите workflow **Build**
5. После завершения скачайте артефакт `vcreactions-jar`
6. Готовый мод будет в файле `vcreactions-1.0.0.jar`

## Установка

1. Установите Fabric Loader для Minecraft 1.26.2
2. Поместите `vcreactions-1.0.0.jar` в папку `mods`
3. Также поместите туда:
   - Fabric API
   - Simple Voice Chat
   - Mod Menu (опционально)
